# The Adire Renova (TAR) — E-commerce Monorepo Build Plan

## Overview
Premium online store for **The Adire Renova** (adire/African dye fabrics, Kaduna, Nigeria). Orange / green / white palette, ShopLuxe-style layout as reference but re-interpreted with rich motion, premium typography, and an artisan-textile identity. Currency: NGN (₦) via Paystack.

## Architecture

**Monorepo (pnpm workspaces + Turborepo), managed with Git/GitHub:**
```
adirerenova/
├── apps/
│   ├── web/        # Next.js 15 (App Router) storefront — customer-facing
│   └── api/        # NestJS backend (products, orders, payments, admin, IG sync)
├── packages/
│   ├── ui/         # Shared design system (tokens, motion primitives, components)
│   ├── types/      # Shared DTOs/types (zod schemas)
│   └── config/     # Shared eslint/ts/tailwind configs
├── scripts/
│   └── instagram-sync/   # One-time IG → R2 sync script (yt-dlp based)
└── docs/
    ├── sitemap.md           # Site map & information architecture ("graphify" role)
    ├── design-principles.md # Design system principles, motion language, tokens
    └── architecture.md
```

Note: a "graphify" skill isn't available in this environment — its purpose (site mapping + principles) is captured in `docs/sitemap.md` and `docs/design-principles.md` instead.

## Key technical decisions

1. **Hosting on Cloudflare**
   - **Next.js storefront** → Cloudflare Workers via `@opennextjs/cloudflare` (official, production-ready), assets on Cloudflare.
   - **NestJS API** → Cloudflare **Containers** (currently the only way to run a full Node/NestJS app on Cloudflare). Fallback if Containers is unavailable in your account: deploy the NestJS app to a VPS/Fly.io and keep everything else on Cloudflare — decided at deploy time, zero code impact.
   - **Storage** → Cloudflare R2 (S3-compatible) via `@aws-sdk/client-s3` presigned uploads for admin product images and imported Instagram media.

2. **Database — Supabase (Postgres)**
   - Prisma ORM inside NestJS pointed at Supabase's connection pooler (pgbouncer-compatible mode).
   - Tables: `products`, `product_variants` (fabric length/type), `categories`, `collections`, `orders`, `order_items`, `customers`, `payments`, `instagram_posts`, `admin_users`, `addresses`, `inventory_logs`, `coupons`.
   - Supabase Auth for customer accounts (email + phone/OTP); admin auth via NestJS guards over a separate admin table.

3. **Payments — Paystack**
   - Initialize transaction (server) → redirect checkout → webhook (`/payments/webhook`) with HMAC signature verification → mark order paid, decrement stock, send confirmation email (Resend or Cloudflare Email Workers — decided at build time).
   - Paystack supports NGN bank transfer + cards; test mode for development.

4. **Instagram sync (one-time)**
   - `scripts/instagram-sync/` uses **yt-dlp** (`yt-dlp https://www.instagram.com/@<handle>/ --cookies-from-browser`) to download all posts (images + videos) from TAR's public handle, uploads to R2 under `ig/<date>/`, and writes metadata (caption, date, media URL, type) into `instagram_posts`. The storefront shows these as a shoppable "From our Instagram" gallery; admin can convert any IG post into a product.

## Storefront — pages (Next.js)

- **Home**: animated hero (full-bleed adire fabric macro shot, staggered text reveal, parallax), marquee value-strip ("Hand-dyed in Kaduna • 100% cotton • Nationwide delivery"), featured collections, product grid, IG gallery, testimonials, newsletter.
- **Shop / Collection**: filterable product grid (category, price, fabric type), animated grid transitions (shared layout animations via Framer Motion), quick-view modal.
- **Product detail**: image gallery with zoom, variant selector (yard length), fabric story section, related products, smooth add-to-cart.
- **Cart** (drawer + page), **Checkout** (delivery details → Paystack), **Order confirmation/tracking**.
- **About / Our Craft** (dyeing process story page), **Contact**, **FAQ/Shipping**, **Auth** (sign in, account, order history).
- **Design system**: Tailwind v4 with custom tokens (deep orange `#E8590C` family, forest/emerald green, warm off-white), serif display font (e.g. Fraunces) + clean sans (Inter/Geist), Framer Motion for page transitions, scroll reveals, hover micro-interactions; premium feel via generous whitespace, large imagery, subtle grain/texture overlays.

## Admin dashboard (Next.js route under `/admin`, protected)
Dashboard (sales stats), Products CRUD with R2 image upload + drag-drop reorder, Orders & fulfillment status, Inventory, Instagram gallery manager (convert posts → products), Coupons, Customers.

## NestJS API modules
`Auth`, `Products`, `Categories/Collections`, `Orders`, `Payments (Paystack)`, `Instagram`, `Uploads (R2 presigned)`, `Admin`, `Customers`, `Notifications`. REST + Swagger docs at `/docs`. Zod/class-validator DTOs shared into `packages/types`.

## Skills to be loaded at build time
`impeccable` + `ui-ux-pro-max` + `design-taste-frontend` for the storefront design; `ponytail` for code quality; `supabase-postgres-best-practices` for schema.

## Build order (milestones)
1. Monorepo scaffold, configs, CI (GitHub Actions: lint/typecheck/build), design tokens + docs (sitemap, principles).
2. Supabase schema (Prisma migrations) + NestJS skeleton with Auth/Products modules.
3. Storefront: layout, home, shop, product pages (the "build the website first" priority — done to visual polish before checkout).
4. Cart + checkout + Paystack integration + webhooks.
5. Admin dashboard.
6. Instagram → R2 sync script + gallery.
7. Cloudflare deployment (Workers + Containers + R2 + custom domain, secrets via `wrangler`).
